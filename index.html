Opponent's decklist (optional — defaults to a preset deck)

Card data is pulled live from Scryfall, so most real Magic cards will work. Effects not yet modeled by the built-in patterns are handed to an AI interpreter (if the server has an API key configured) before falling back to no game effect.

"Watch AI vs AI" plays both decks against each other with a bot on both sides, paced with a delay between moves so you can follow along — a speed slider in the game screen itself lets you adjust the pace live, mid-game. Use the preset/saved-deck dropdowns above each decklist to quickly load a ready-made deck (including Commander presets with their commander already filled in), or save whatever you've pasted under your own name for next time.
